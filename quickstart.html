快速开始

在本地把 Horizon 前后端完整跑起来大约需要十分钟。命令与 docs/local-development.md 保持一致。

环境要求

依赖版本说明
Node.js≥ 22.23.2前端构建与工具链
pnpm10.14.0使用锁文件版本安装依赖
Go1.27.3scripts/go.sh 优先使用项目内 .tools/go，不修改系统 Go
Docker支持 Compose运行 PostgreSQL

安装

sh
git clone https://github.com/itophp/horizon.git
cd horizon
cp .env.example .env
pnpm install --frozen-lockfile  # 按锁文件版本安装

启动

  1. 准备工具与数据库

    sh
    make tools      # 安装项目内 Go 工具链
make db-up      # 启动 PostgreSQL 容器
make migrate    # 执行数据库迁移

  2. 初始化管理员账号

    在终端安全输入一个 12–128 字符的初始密码，不使用预设默认密码：

    sh
    # read -s 不会回显密码
read -s BOOTSTRAP_PASSWORD; export BOOTSTRAP_PASSWORD
BOOTSTRAP_USERNAME=admin make bootstrap
unset BOOTSTRAP_PASSWORD
    初始账号由 make bootstrap 创建；已存在的工作区不会被重复初始化覆盖。默认工作区为 workspace-default。

  3. 启动 API 与 Web

    sh — 终端 1
    make dev-api
    sh — 终端 2
    make dev

  4. 访问并验证

    打开 http://127.0.0.1:5173，进入 /login 使用刚创建的账号登录。API 健康检查为 http://127.0.0.1:8080/api/health；Vite 把同源 /api 代理给 Go，不需要开放 CORS。

常用命令

命令作用
make generateGoa → OpenAPI；sqlc；Orval → TanStack Query SDK
make ci-fast无需数据库与浏览器的完整快速门禁
make lint / make testESLint + Go vet / 前端与 Go 单元测试
make test-integration独立 PostgreSQL schema 中的集成测试
make test-e2e启动真实前后端的端到端测试（需独立端口 5179/8099）
make db-down停止数据库容器，开发数据卷保留
pnpm webmcp启动 WebMCP 服务（默认 127.0.0.1:18793）
测试节奏：日常开发累计待验项，阶段验收或提交前统一跑快速门禁。详见 测试与质量门禁。
